# Impeccable Design Context — juguitsu

## Design Context

### Users

Power users who live in jj/git repos on disk — reviewing history, working copy changes, and bookmarks without a hosted account. They use juguitsu in long desktop sessions alongside an editor and terminal. The job is to move through repos, revisions, and diffs quickly with keyboard-first flows and zero perceived wait on local data.

### Brand Personality

**Calm · precise · local-first**

The interface should feel settled and trustworthy, not loud or promotional. Information is exact (mono for ids/paths, jj vocabulary). The UI reads from disk and cache first; network is explicit for remotes only.

### Aesthetic Direction

- **Visual tone**: Industrial workbench — dense panels, neutral surfaces, one blue accent, status over decoration
- **References**: Linear (minimal chrome, fast workbench rhythm); jj mental models via sm17p-design (bookmarks, not “branch” in copy)
- **Anti-references**: GitHub marketing purple, SaaS dashboard cards, hero empty states, spinners on navigation, gradient text, side-stripe alerts, AI cyan-on-dark
- **Theme**: System light/dark via `prefers-color-scheme` (tokens in `src/index.css`)

### Design Principles

1. **Local-first perceived speed** — show last-known tree/log immediately; refresh in background; no blocking spinners on navigation
2. **Keyboard-first** — every primary action has a shortcut or ⌘K entry; document shortcuts in UI
3. **Calm density** — 13–14px body, tight but readable; mono for machine strings; generous hierarchy through spacing rhythm, not decoration
4. **One accent per surface** — selected tab, focused row, primary Open; avoid competing glows or card grids
5. **Motion with restraint** — color/background ≤150ms; transform/opacity only for layout motion; respect `prefers-reduced-motion`

### Stack & Tokens

- React 19 + Ark UI + Tailwind v4 `@theme` in `src/index.css`
- Components: `src/components/`; shared logic: `src/lib/`
- Pierre Trees/Diffs for file tree and diff views when integrated
- Tauri invoke for all jj/filesystem IO

### Quality Bar

MVP workbench shell now; flagship polish on diff/history/⌘K flows as they land. Ship functional first, polish pass before each major surface ships.
